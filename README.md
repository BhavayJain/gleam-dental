# Gleam Dental

A professional dental clinic website built with a modern glassmorphism design aesthetic — frosted, translucent cards layered over rich gradient backgrounds to create a clean, trustworthy feel. The site will feature a hero section highlighting the clinic and doctor, a services showcase displaying dental treatments, an "About the Doctor" section with credentials and specialization, and an online appointment booking flow for patients.

Building with Next.js and TypeScript.
